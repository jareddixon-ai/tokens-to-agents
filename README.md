# Tokens to Agents

A 7-module course on working with AI language models, built while teaching
myself from no technical background.

**[Open the course →](https://jareddixon-ai.github.io/tokens-to-agents/)**

## What's in it

1. **The machine** — what a language model is really doing
2. **Prompting** — the only interface skill that compounds
3. **Context & RAG** — giving it your world
4. **Tools and agents** — giving the model hands
5. **Building it yourself** — starting today
6. **Trust, failure, and the judgment that makes you good**
7. **Staying current** — without drowning

Plus flashcard decks and a glossary.

## Why I built it

I'm an economics major, not a computer scientist. Most explanations I found
were either marketing or written for people who already knew. So I built the
version I wanted: ground up, no assumed background, and quizzes that make you
apply an idea rather than recall a definition.

## A note on the tutor

The course has a built-in tutor that answers questions as you work through it.
It runs on Claude's infrastructure, so it's only active on the Claude-hosted
version — here it's disabled and the page says so. The modules, quizzes,
flashcards, and glossary all work on this version.
